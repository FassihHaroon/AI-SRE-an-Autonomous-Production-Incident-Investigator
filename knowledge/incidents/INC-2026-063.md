# INC-2026-063: Feature flag leaked database connections until the pool was exhausted

> Synthetic postmortem for the simulated environment (training/evaluation data).

## What happened

Enabling an audit feature flag opened a second connection per lookup that was never released on one code path. Sessions piled up 'idle in transaction' and the pool emptied over ~2 minutes.

## How it was detected and diagnosed

Pool at max at normal traffic, query latency normal, pg_stat_activity full of idle-in-transaction sessions from orders-service.

## Resolution

Flag disabled; a restart released the connections. Restarting alone only helped for minutes.
