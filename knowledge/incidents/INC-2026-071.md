# INC-2026-071: api-gateway memory leak from an unbounded in-process cache (OOM restart loop)

> Synthetic postmortem for the simulated environment (training/evaluation data).

## What happened

A release cached recommendations in process memory without eviction. Memory grew linearly with product-detail traffic until the container was OOM-killed; it restarted and leaked again.

## How it was detected and diagnosed

Sawtooth resident memory; process_start_time changes every few minutes; correlation with the deploy.

## Resolution

Rolled back; cache re-implemented with an LRU bound. Restarts were only a temporary mitigation.
