# INC-2026-044: Redis node unreachable: carts down, orders charged but not queued

> Synthetic postmortem for the simulated environment (training/evaluation data).

## What happened

A network change black-holed traffic to the Redis host. Catalog reads fell back to the database (slower), carts returned 503 and order placement failed after payment because the fulfilment job could not be enqueued.

## How it was detected and diagnosed

Client-side Redis timeouts on every service at the same instant; redis_up dropped to 0; no deploy.

## Resolution

Network change reverted. 312 paid-but-unqueued orders were re-driven manually.
