# INC-2026-052: Fulfilment backlog after shipping-label client upgrade

> Synthetic postmortem for the simulated environment (training/evaluation data).

## What happened

fulfilment-worker 1.5.0 pointed its label client at a staging endpoint. Each job hung until the 2 s timeout and most failed, so the queue grew for over an hour while the API looked healthy.

## How it was detected and diagnosed

Queue depth and oldest-job age rose linearly; worker failures by reason LabelServiceTimeoutError; API error rate unchanged, which delayed detection.

## Resolution

Rolled back to 1.4.3; backlog drained in 3 minutes; dead-letter queue re-driven.
