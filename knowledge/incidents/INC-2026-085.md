# INC-2026-085: Network latency to the database host slowed every query

> Synthetic postmortem for the simulated environment (training/evaluation data).

## What happened

A degraded network path added ~100 ms per round trip to PostgreSQL. Every DB-backed endpoint slowed in proportion to its query count; the database itself was idle.

## How it was detected and diagnosed

Uniform per-query latency increase across services and query shapes; pg_stat_statements times normal.

## Resolution

Traffic moved to a healthy path by the network team.
